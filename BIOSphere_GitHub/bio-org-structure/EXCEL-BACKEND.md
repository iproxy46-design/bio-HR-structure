# PostgreSQL и прежние Excel-данные

Кнопки «Шаблон Excel», «Выгрузить Excel» и «Загрузить Excel» убраны из интерфейса.
Сотрудники и структура редактируются в админке и сохраняются в PostgreSQL.

Если данные уже загружены в старую серверную версию, повторно загружать Excel
не нужно. Переносите актуальные серверные данные через `export-legacy.mjs`
и `migrate-postgres.ts`: вместе с сотрудниками сохраняются дерево, контакты
и фотографии. Миграция допускается только в пустую PostgreSQL-базу.
Порядок обновления сервера приведён в README.md.

Служебный Excel API оставлен для совместимости и доступен только администратору.
Он не вызывается при запуске или деплое. Его прежний импорт сопоставляет строки
с `source-N` и не предназначен для первоначального заполнения пустой базы.
